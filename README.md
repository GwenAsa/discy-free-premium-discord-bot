## ✨ Why Discy?

Discy is a **multi-purpose Discord bot** built with Python and `discord.py`. It puts the tools a community actually needs into one clean, consistent bot: moderation, server insight, utilities, and ready-made panels for tickets and roles.

<div align="center">

| 🛡️ | 🔎 | ⚡ | 🎫 |
|:-:|:-:|:-:|:-:|
| **Moderation** | **Server utilities** | **Automation** | **Community systems** |
| Kick, ban, timeout, warnings, purge, lockdown | Deep info on servers, roles, channels and members | Polls, timestamps, calculator, echo | Ticket panels and role selection panels |

</div>

- 🧩 **46 slash commands** with Discord's native suggestions and autocomplete
- 🎨 **Consistent embeds** across every response
- 🏗️ **Modular cog architecture** that keeps features separated and easy to grow
- 🆓 **Free to use**

## 📚 Commands

Discy uses Discord application commands. Type `/` in any channel and pick a command. Expand a category to see everything inside it.
