## About Discy

**Discy** is a community-focused Discord bot built to make server management and everyday interactions simpler.

Developed with Python and `discord.py`, Discy uses a modular architecture that keeps features organized and makes future improvements easier to implement.

The vision is to deliver a practical, reliable, and continuously improving Discord experience without putting essential community tools behind a premium subscription.

**Free to use. Built to grow. Designed for communities.**

## Commands

Discy uses Discord application commands, allowing users to discover and execute commands through Discord's native interface.

| Command       | Description                               |
| :------------ | :---------------------------------------- |
| `/ping`       | Check bot latency and responsiveness      |
| `/help`       | Discover available commands               |
| `/about`      | Learn about Discy                         |
| `/botinfo`    | View information about the bot            |
| `/serverinfo` | View information about the current server |
| `/userinfo`   | View information about a server member    |
| `/avatar`     | View a user's avatar                      |
| `/invite`     | Access the bot invitation link            |
| `/uptime`     | Check how long Discy has been running     |
| `/stats`      | View available bot statistics             |

*The command list should reflect the commands implemented and deployed in the current version.*

## Getting Started

Interested in running your own instance of Discy?

You will need Python, a Discord application, a bot token, and the project's source code.

1. Clone the repository.
2. Create and activate a Python virtual environment.
3. Install the dependencies listed in `requirements.txt`.
4. Configure the required environment variables.
5. Start the bot using the documented entry point.

Detailed installation instructions should be provided alongside the source code before this section is treated as a complete setup guide.
